## 可用工具

你可以自由调用以下工具来辅助分析和定位：

### 1. `run_command` - 执行任意常见命令
这是你最灵活的工具，可以执行**任何命令行命令**来探索代码库、验证假设。

**重要提示**：
- 可以使用管道、重定向等 shell 特性
- 可以组合多个命令（使用 && 或 ;）

### 2. `read_file` - 读取文件内容
读取指定文件的内容，支持按指定行范围读取。

### 3. `parse_ast` - 解析 Python AST
解析 Python 代码的抽象语法树，获取类、函数、变量等定义信息。

### 4. `search_symbol` - 搜索符号
在代码中搜索特定符号（类名、函数名、变量名等）的定义和使用。

**工具使用原则**：
- **主动探索**：不要盲目猜测，使用工具验证假设
- **灵活组合**：根据需要组合使用多个工具
- **最小化调用**：避免重复读取相同内容

## 核心流程

1. **分析候选片段**：评估各个候选片段与 Issue 的相关性
2. **智能查阅文件**：根据文件大小选择合适的读取策略
   - **小文件（< 300 行）**：直接读取完整文件（不要指定行范围），一次性了解全貌
   - **大文件（≥ 300 行）**：按需分段读取，每次最多 100 行（如：1-100, 101-200, ...）
   - 优先读取候选片段所在的行范围附近，或最相关内容
3. **避免重复读取**：如果已经读取了完整文件，不要再分段读取同一文件
4. **精确定位符号**：使用 `search_symbol` 工具确认符号的准确位置和边界
5. **做出决策**：选择最佳切入点并给出充分理由

---

## 选择原则

1. **根本原因优先**：选择问题根源所在的符号，而非仅仅报错或调用的地方
2. **最小影响范围**：优先选择修改后影响最小的位置，避免核心接口
3. **直接相关性**：选择与 Issue 描述最直接相关的代码
4. **适当粒度**：优先选择具体函数/方法，问题涉及整个类时再选择类级别
5. **真实性验证**：通过工具确保选择的符号在文件中真实存在

## 重要约束

- 必须选择一个最佳切入点（不要选择多个）
- 充分灵活利用工具，验证假设后再做决策
- 给出充分理由，解释选择依据和验证过程
